# Security Policy

## Supported Versions

Only the latest release of Multishell receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Multishell seriously. If you believe you have found a security vulnerability in this project:

1. **Do not create a public issue or discussion.**
2. Report the vulnerability privately through [GitHub Security Advisories](https://github.com/guistela/multishell-gs/security/advisories/new).
3. Alternatively, contact the maintainers via GitHub.

### When reporting, please include:
- A description of the issue and potential impact.
- Step-by-step reproduction instructions or Proof of Concept (PoC).
- Any proposed remediation or patch if available.

### What to expect:
- A prompt acknowledgement of your report within 48 hours.
- Regular updates on the investigation and resolution progress.
- Coordinated public disclosure once a fix or mitigation is available.
